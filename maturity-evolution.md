# Test — Insight maturity evolution

## History sequence

1. Customer segmentation
2. Opportunity classification
3. Risk grading
4. Product prioritization
5. Sales ranking
6. A new workflow independently introduces states, thresholds and triggers

## Expected behavior

The system should not jump from item 1 directly to a Personal Principle.

A reasonable evolution is:

```text
Observation
→ Weak Signal
→ Emerging Pattern
→ Strong Insight
→ possible Personal Principle after predictive confirmation
```

## Failure conditions

- maturity rises merely because time passed
- repeated discussion of one project is counted as independent evidence
- no search for counterexamples
